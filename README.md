# Backend Exercises

> School backend programming exercises in C#, covering server-side concepts and API fundamentals.

![Language](https://img.shields.io/badge/Language-C%23-purple) ![Type](https://img.shields.io/badge/Type-School%20Assignments-orange)

## About

A collection of backend programming exercises completed during game development studies. These assignments explore server-side programming, REST APIs, databases, and networking concepts — skills that complement game development work such as online multiplayer, leaderboards, and cloud saves.

## Topics Covered

- REST API design and consumption
- HTTP request/response handling
- JSON serialization and deserialization
- Database interactions (CRUD operations)
- Authentication basics
- Server-client communication patterns

## Getting Started

### Prerequisites

- .NET SDK (6.0 or later recommended)
- An IDE such as Visual Studio or VS Code with C# extension

### Running an Exercise

```bash
cd ExerciseName/
dotnet run
```

## Context

Completed as part of a game programming curriculum at HAMK or similar institution. Backend knowledge is directly applicable to building online game services, multiplayer infrastructure, and game data persistence systems.
